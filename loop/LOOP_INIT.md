This repository is a workspace for [Apart Research's Swarm Alignment Hackathon](https://apartresearch.com/sprints/swarm-alignment-2026#overview),
held November 6–8, 2026. The event explores alignment challenges that arise when
AI agents interact, including through negotiation, trade, and shared tools.
